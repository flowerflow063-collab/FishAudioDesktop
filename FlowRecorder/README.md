# FlowRecorder

Grabador de pantalla para Windows inspirado en el flujo de trabajo de OBS, construido desde cero.

## Versión 1

- Vista previa de la pantalla.
- Selección de monitor.
- 15/24/30/60 FPS.
- Grabación de pantalla en MP4.
- Grabación opcional de micrófono.
- Mezcla automática de vídeo y micrófono.
- Carpeta de salida configurable.
- Instalador/ZIP generado automáticamente con GitHub Actions.
